Deskhand 0.1.0 Preview

Apple Silicon Mac / macOS 26 이상

1. Deskhand.app을 Applications 폴더로 드래그합니다.
2. 디스크 이미지를 추출하고 응용 프로그램 폴더에서 Deskhand를 실행합니다.
3. 'PC 추가'에서 준비된 Windows PC의 SSH 별칭을 선택해 에이전트를 연결합니다.
4. '화면' 탭에서 Windows 계정 암호로 로그인합니다. Windows PIN은 계정 암호가 아닙니다.

Windows는 원격 데스크톱 호스트를 지원하는 에디션에서 원격 데스크톱과 SSH 연결을 먼저 준비해야 합니다.
Windows Home은 원격 데스크톱 호스트를 지원하지 않습니다.
물리 모니터를 켜 두거나 Deskhand 가상 디스플레이 드라이버를 설치할 필요는 없습니다.

이 버전은 신뢰하는 개인 PC와 사용자 환경을 대상으로 한 프리뷰입니다.
AI 범위 설정은 동일 사용자 프로세스에 대한 보안 격리가 아닙니다.
큰 창에서 CPU 사용량과 메모리가 늘어나며, 60fps를 보장하지 않습니다.
Windows 계정 암호를 저장하지 않으므로 앱을 다시 실행하면 다시 로그인해야 합니다.
자세한 검증 범위와 남은 제한은 GitHub 릴리즈 노트를 참고하세요.
