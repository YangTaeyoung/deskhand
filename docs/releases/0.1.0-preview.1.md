# Deskhand 0.1.0 Preview 1

Mac에서 Windows PC의 화면·터미널·파일·프로세스·로그·디버거·QA를 다루는 첫 설치형 프리뷰입니다.

## 다운로드와 설치

- `Deskhand-0.1.0-preview.1-macos-arm64.dmg`: Apple Silicon Mac, **macOS 27 이상**.
- DMG를 열고 `Deskhand.app`을 `Applications`로 드래그합니다.
- Intel Mac 빌드와 자동 업데이트는 이번 배포에 포함하지 않습니다.
- 연결할 Windows는 SSH 접속과 원격 데스크톱이 준비돼 있어야 합니다. Windows Home은 RDP 호스트를 지원하지 않습니다. [Microsoft 설정 안내](https://learn.microsoft.com/windows-server/remote/remote-desktop-services/remotepc/remote-desktop-allow-access).

## 포함한 기능

- Deskhand 앱 안에서 Windows RDP 화면과 계정 로그인. 외부 원격 앱과 자체 디스플레이 드라이버를 요구하지 않습니다.
- 창 크기에 맞춘 자동 해상도. 기본값은 Retina 확대 없이 화면 영역 1포인트당 원격 1픽셀입니다.
- 자체 에이전트·CLI/MCP 작업 경로와 세션·제어권을 검사하는 입력 스트림.
- RDP 서버 인증서 고정, NLA 연결, 메모리에서만 사용하는 계정 암호.
- 프레임 수신·레이어 제출의 로컬 진단 계측. 암호나 화면 픽셀을 기록하지 않습니다.

## 현재 성능과 제한

현재 개발 빌드로 40초 동안 화면 전체를 계속 갱신한 시험에서 작은 창 1020×601은 Windows 출력 중앙값 31fps, Mac 앱 CPU 약 22%·RSS 약 176MiB였습니다. 큰 창 2748×1463은 중앙값 31fps, 순간 22fps, CPU 약 119%·RSS 약 506MiB였습니다. CPU는 코어 하나를 100%로 계산한 값입니다. 서버 출력 FPS이며 모니터 표시 완료 FPS나 60fps 통과 판정이 아닙니다.

이 버전은 신뢰하는 사용자·PC 환경에서 사용하는 프리뷰입니다. AI 범위 설정은 같은 Mac 사용자가 실행하는 프로세스에 대한 보안 샌드박스가 아닙니다. 경로 심볼릭 링크·정션, 이미 열린 세션, 클라이언트 종류 위장 등 남은 제한이 있고 개인정보·산출물 보존 설정의 전체 강제도 완료되지 않았습니다. 무인 AI를 서로 신뢰하지 않는 사용자와 격리하는 용도로 검증하지 않았습니다.

전체 품질·장기 안정성·모든 재연결 경로의 상업용 완료를 선언하는 릴리즈가 아닙니다. 암호를 저장하지 않으므로 앱 재실행 시 Windows 계정으로 다시 로그인해야 합니다. Windows ARM64 에이전트는 포함하지만 해당 실기기 검증은 하지 않았습니다.

## 오픈소스 구성

앱에 FreeRDP·WinPR·OpenSSL·json-c·FFmpeg 라이선스와 고정 FFmpeg 소스·빌드 설정·DISP 패치를 포함했습니다. 시스템의 Homebrew GPL FFmpeg 라이브러리를 배포하지 않습니다.

배포 앱은 별도의 Release 구성입니다. 위 성능 수치를 Release 구성의 추가 실측값으로 해석하지 않습니다. macOS 최소 버전은 포함된 네이티브 라이브러리의 실제 배포 대상을 검사해 27.0으로 맞췄습니다.
