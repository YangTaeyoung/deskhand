# Deskhand 0.1.0

Mac에서 Windows PC를 보고 직접 조작하면서 AI 작업을 함께 진행할 수 있는 첫 정식 배포입니다.

## 설치

`Deskhand-0.1.0-macos-arm64.dmg`를 열어 앱을 Applications로 옮깁니다. Apple Silicon과 macOS 27 이상이 필요합니다. Windows는 SSH와 원격 데스크톱 호스트가 준비돼 있어야 합니다. Intel Mac과 자동 업데이트는 지원하지 않습니다.

## 주요 기능

- Windows 화면을 함께 보면서 조작합니다. 사람이 입력하면 우선권을 갖고, 입력을 마친 뒤 5초 동안 조작하지 않으면 AI가 이어갑니다. 긴급 정지는 자동 해제되지 않습니다.
- 선택한 Windows 로그인 정보를 Mac 키체인에 저장해 다시 연결할 수 있습니다.
- 전용 PC에서 콘솔 인계와 Windows 자동 로그인을 설정하면 RDP 연결 종료와 재부팅 뒤에도 작업을 복구할 수 있습니다. 준비와 검증 절차는 [무인 운용 안내](https://github.com/YangTaeyoung/deskhand/blob/v0.1.0/docs/UNATTENDED.md)를 참고하세요. 설정 스크립트는 [prepare-unattended.ps1](https://github.com/YangTaeyoung/deskhand/blob/v0.1.0/scripts/windows/prepare-unattended.ps1)과 [console-handoff.ps1](https://github.com/YangTaeyoung/deskhand/blob/v0.1.0/scripts/windows/console-handoff.ps1)입니다.
- Mac 화면 앱 종료 뒤 직접 UDP 연결이 거부되는 환경에서, SSH 키 인증이 준비돼 있으면 인증된 SSH 중계를 통해 연결을 복구합니다.
- 작업의 중단·시간 초과·연결 장애에서 실행 결과가 불명확한 명령은 자동으로 다시 실행하지 않습니다.

## 사용 범위와 제한

신뢰하는 사용자와 전용 Windows PC를 대상으로 합니다. AI 범위 설정은 같은 Mac 사용자가 실행하는 프로세스에 대한 보안 샌드박스가 아닙니다. 심볼릭 링크·정션, 이미 열린 세션, 클라이언트 종류 위장 및 개인정보·산출물 보존 설정에는 제한이 있습니다. 잠금 없는 콘솔 인계와 자동 로그인은 PC에 물리적으로 접근할 수 있는 사람에게도 접근을 허용합니다. 앱이 닫힌 동안의 복구는 데몬 실행 및 Windows SSH 연결과 키 인증에 의존합니다.

Windows ARM64 에이전트는 실기기 검증을 하지 않았습니다. 대형 화면에서는 CPU와 메모리 사용량이 증가하며 60fps를 보장하지 않습니다. 장기 무인 운용과 모든 네트워크 복구 경로는 검증 범위에 포함되지 않습니다. 실측 내용은 [검증 기록](https://github.com/YangTaeyoung/deskhand/blob/v0.1.0/docs/acceptance/unattended.md)을 참고하세요.

앱에는 FreeRDP, WinPR, OpenSSL, json-c 및 FFmpeg의 라이선스와 관련 소스·빌드 설정을 포함합니다.
