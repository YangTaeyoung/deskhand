# Deskhand Mac 앱 트랙 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 상업용 품질의 macOS 앱 `Deskhand.app` — 컴퓨터 목록·추가, 작업 공간(실시간 화면·터미널·파일·프로세스·로그·디버거·QA·타임라인), 제어권 인계 UI를 만든다. 데몬 로컬 API에 붙고, 데몬 없이도 미리보기 데이터로 모든 화면을 렌더링해 스냅샷으로 검수할 수 있다.

**Architecture:** XcodeGen `app/project.yml`의 앱 타깃은 얇은 진입점이다. 뷰·상태·클라이언트·미디어는 SwiftPM 패키지 `app/DeskhandKit`에 둔다. 앱과 스냅샷 렌더러(`DeskhandSnapshots` 실행 파일)가 같은 `DeskhandUI` 모듈을 쓴다. 모든 화면은 `Backend` 프로토콜 뒤에서 동작하며 `LiveBackend`(데몬)와 `PreviewBackend`(고정 데이터)가 있다.

**Tech Stack:** Swift 6.x(Xcode 27.1, 엄격한 동시성), SwiftUI + AppKit, macOS 26.0 이상, Network.framework(unix socket), VideoToolbox·CoreMedia·AVFoundation(`AVSampleBufferDisplayLayer`), SwiftTerm(MIT, SPM), XcodeGen.

**Spec:** `docs/design.md` §6·§7·§13, `docs/local-api.md`, `docs/protocol.md` §4–§7.

## Global Constraints

- 배포 대상 macOS 26.0, Swift 언어 모드 6, `SWIFT_STRICT_CONCURRENCY: complete`. 경고 없는 빌드.
- 번들 ID `io.github.yangtaeyoung.Deskhand`, 앱 이름 `Deskhand`, 카테고리 `public.app-category.developer-tools`.
- 데몬 소켓 `~/Library/Application Support/Deskhand/run/d.sock`(환경 변수 `DESKHAND_HOME`이 있으면 `$DESKHAND_HOME/run/d.sock`). 프로토콜은 `docs/local-api.md` 그대로.
- UI 문자열은 한국어, `Localizable.xcstrings`(또는 `String(localized:)`)로 분리. 키·식별자는 영어.
- 의미 색: 사람 조작 `Color.blue`(시스템), AI 조작 `Color.purple`(시스템), 관찰 `Color.secondary`, 위험·긴급 정지 `Color.red`, 성공 `Color.green`, 경고 `Color.orange`. 앱 강조색 `Color.indigo`. 고정 hex 색을 화면 코드에 직접 쓰지 않고 `DesignSystem`의 토큰만 쓴다.
- 글꼴: 시스템(SF Pro), 경로·ID·터미널은 `.monospaced`. 간격은 4의 배수(4/8/12/16/24/32).
- SF Symbols만 쓴다. 외부 이미지 에셋은 앱 아이콘뿐.
- 모든 화면에 빈 상태·로딩·오류 상태가 있다. 진행 중인 원격 작업은 항상 진행 표시가 보인다.
- 키보드: ⌘1–⌘7 탭 전환, ⌘⇧. 긴급 정지, ⌘K 컴퓨터 빠른 전환, ⌘, 설정. 모든 버튼에 VoiceOver 레이블.
- OS 키체인에 접근하지 않는다. 화면 녹화 권한이 필요한 API를 쓰지 않는다(스냅샷은 오프스크린 렌더링).
- 주석은 코드가 지금 하는 일만 쓴다.
- Swift 패키지 의존성은 SwiftTerm 하나만 추가한다.

## Review Focus

1. **데몬이 없거나 죽음** — 앱은 데몬을 띄우고, 실패하면 "데몬을 시작할 수 없습니다" 오류 상태와 재시도·로그 열기를 보여 준다. 멈춘 스피너 금지. → A2 `testReconnectsAfterDaemonRestart`, A3 오류 상태 스냅샷.
2. **AI가 조작 중일 때 사람이 화면을 클릭** — 입력은 보내지 않고 확인 팝오버("AI가 조작 중입니다. 제어권을 가져올까요?")를 띄운다. → A5 `testHumanInputBlockedWhileAIOwns`.
3. **해상도·Retina 배율·창 크기 변경** — 마우스 좌표가 원격 원본 픽셀로 정확히 환산된다(레터박스 영역 클릭은 무시). → A5 `testPointMappingWithLetterbox`.
4. **한글 입력** — 기본 모드는 스캔코드 전송, "Mac 입력기 사용" 모드는 확정 문자열만 `text`로 보낸다(조합 중 문자 미전송). → A5 `testMarkedTextNotSent`.
5. **긴 경로·한글·이모지 파일명과 수천 개 항목 폴더** — 파일 패널이 잘리지 않게 표시하고 스크롤이 끊기지 않는다(지연 로딩). → A6 스냅샷 `files-long-names`, `testLargeDirectoryPaging`.
