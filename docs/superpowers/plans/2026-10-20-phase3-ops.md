# Deskhand 3단계: 운영 기능 (파일 전송·터미널·진단·터널) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 파일·폴더 양방향 전송(재개·무결성·충돌 정책·검증 후 이동), 원격 내부 복사·이동·휴지통, 대화형 터미널(ConPTY, 재부착), 시스템·서비스·이벤트 로그·크래시 진단, 디버깅용 루프백 TCP 터널을 에이전트·데몬·CLI·MCP에 구현한다.

**Architecture:** 에이전트는 `put`/`get`/`pty`/`tunnel` QUIC 스트림 처리기와 `xfer.*`·`fs.copy/trash/hash`·`pty.list`·`diag.*`·`debug.ports` op를 더한다. 데몬은 `internal/daemon/xfer`(전송 관리자, SQLite 영속), `internal/daemon/pty`(터미널 중계), `internal/daemon/tunnel`(로컬 리스너)을 더하고 로컬 API·CLI·MCP로 노출한다.

**Tech Stack:** Go 1.26, quic-go, golang.org/x/sys/windows(ConPTY: CreatePseudoConsole), Windows shell32(SHFileOperationW) — 모두 순수 Go syscall.

**Spec:** `docs/design.md` §4·§8·§9, `docs/protocol.md` §2·§3.1·§7, `docs/local-api.md` §3(파일·전송·진단·터널·pty)·§4(`kind:"pty"`)·§5·§6·§7, 요구사항 `docs/plan/01-product.md` FILE-01..04, RUN-01, OPS-01, 인수 테스트 A11–A16.

## Global Constraints

- 1단계 Global Constraints 전부.
- 전송: 청크 4 MiB, 파일 동시 4개, 임시 파일 `<대상>.deskhand-part-<transfer_id>`, 최종 sha256 검증 후 반영(MoveFileExW REPLACE_EXISTING|WRITE_THROUGH), 원본 지문(크기·mtime·sha256)이 바뀌면 `TRANSFER_CONFLICT`, 충돌 정책 기본 `fail`.
- move: 목적지 검증 후에만 원본 삭제. 원본 삭제 실패는 `copied_source_retained`. 장치 간 이동은 원자적이라고 표시하지 않는다. rename 실패를 조용히 copy+delete로 바꾸지 않는다.
- 삭제 기본은 휴지통(`fs.trash`), 영구 삭제는 `fs.delete`(데몬은 `permanent:true` 필요).
- 경로: Windows는 `\\?\` 긴 경로를 내부에서 쓰고, 예약 이름(CON, NUL, COM1…)·후행 점/공백·대소문자만 다른 충돌을 명시적 오류로 보고한다. 작업 루트 정책(호스트 설정 `file_roots`, 비어 있으면 제한 없음)이 있으면 junction·symlink 해석 후 루트 밖을 `PERMISSION_DENIED`.
- 기록 대상 op 목록(`internal/wire.JournaledOps`)에 `fs.copy`, `fs.trash`, `xfer.commit`, `xfer.abort`를 더한다.
- 터미널: ConPTY, 기본 셸 `powershell.exe -NoLogo`(설정으로 pwsh·cmd), 스크롤백 1 MiB 보존, 스트림이 끊겨도 프로세스 유지, `exec.kill`로 종료. 사용자 환경·PATH를 바꾸지 않는다(childenv).
- 진단: PowerShell CIM(`Get-CimInstance`)·`Get-WinEvent`를 `exec`와 같은 경로로 실행해 JSON으로 파싱. 결과 필드는 local-api §5 DiagSystem·EventLogEntry.
- 터널: 에이전트는 `127.0.0.1`/`::1`만 연결. 데몬 로컬 리스너도 루프백만.
- 실기기에서 사용자 파일·창을 건드리지 않는다. 테스트 파일은 `C:\Users\apxkf\dev\deskhand-e2e\` 아래(사용자의 Defender 예외 폴더)에만 만들고 끝에 지운다.

## Review Focus

1. **전송 중 연결 끊김·데몬 재시작** — 재연결 후 같은 transfer가 받은 바이트부터 재개하고, 최종 파일 sha256이 원본과 같다. → F3 `TestTransferResumesAfterReconnectAndDaemonRestart`.
2. **이동 중 원본 삭제 실패(파일 잠김)** — 목적지는 남고 결과 `copied_source_retained`, 원본 유지. → F3 `TestMoveKeepsSourceWhenDeleteFails`.
3. **대상 디스크 부족·권한 없음·잠긴 대상 파일** — 오염된 최종 파일 없이 `DISK_FULL`/`PERMISSION_DENIED`/명확한 오류, 임시 파일 정리. → F2 `TestCommitFailureLeavesNoCorruptTarget`.
4. **한글·이모지·260자 넘는 경로·대소문자 충돌·junction 탈출** — 손상·탈출 없이 동작하거나 명시적 오류. → F1 `TestPathEdgeCases`(실기기).
5. **터미널 재부착** — 스트림을 끊었다 다시 붙이면 스크롤백이 보이고 같은 프로세스에 입력이 간다. → F5 `TestPTYReattachKeepsProcess`.
